# API-01: scoped agent graph contract

The version-1 contract is implemented under [protocol/agent-access/v1](../../protocol/agent-access/v1/README.md). Five reserved routes expose immutable context/profile metadata, six tagged scoped reads, five finite graph commands, existing operation status and node-only recovery. JSON Schema 2020-12, OpenAPI 3.1, generated developer type declarations, CLI behavior and portable fixtures support independently generated clients. No root Cargo integration or installed production route was added.

All 30 offline conformance tests pass, including a fresh isolated environment using pinned developer dependencies. Generated schemas/types match their declarations. Tests cover conditional writes, every batch/endpoint check, all eight read relationship classes, context/pinned-revision/history/search scope, credential-class separation, generation/expiry refusal, frozen bindings, changed-payload conflicts, commit-before-response-loss replay, bounded recovery and immutable terminal outcomes. [Machine-readable evidence](API-01.json) records source/spec hashes, the contract inventory and raw logs. The fixture ledger/service are developer-only in-memory oracles, not runtime authorization or durable AQ state.

A separate narrow Docker probe used graph source `225329cd6acf5a775fd2a0b016dd1c45fb16c79b`, qualified image `sha256:807beba98dcd20b0ae335f09cae8c06ecb182a352ee78de278cb47fccb2ee3be` and synthetic isolated resources. Actual public HTTP responses are retained as realistic offline fixtures. A no-op source-version guard and edge write succeeded atomically; identical requests replayed one receipt; stale guards returned 409 without adding an edge; foreign-authored knowledge and retired sources returned 403 under the ordinary writer. Source inspection confirmed expected-version and author/protection checks precede no-op detection. No graph source was changed; test containers/network were removed.

The command allowlist prevents forwarding lifecycle, approval, arbitrary metadata, credentials, actor claims or publication control through record correction. Decomposition creates an unapplied draft. Edge operations require readable endpoints, writable source, permitted types and conditional guards; structural proposals guard every existing endpoint. An unavailable guard must be rejected without administrator fallback or an unguarded write. Node recovery cannot create intents or perform graph queries. Unknown effects preserve the original operation identity and bounded retry state; only confirmed receipts can produce confirmed-event facts, and they never imply task completion.

Reproduce with the commands in the contract README. Ordinary tests need no daemon, graph, worker, Docker, database, sibling checkout or credentials. Python dependencies are strictly developer tooling; a fresh-environment check caught and resolved a generated filename collision with Python's standard library. Actual gateway authentication/scoped traversal, durable delivery/outbox atomicity and production agent CLI/cache remain AQ-06, AQ-07 and WRK-05 work. API-01 does not close a production authorization, full recovery, deployment or capacity gate.
