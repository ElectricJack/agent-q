## Changes and scope

The server Dockerfile default must match `STATE_FORMAT_VERSION` (41), with a
Cargo regression test reading its numeric default. A second test checks the
default maximum worker protocol against `SUPPORTED_WORKER_PROTOCOLS.1` (1).
The integration test reads the Dockerfile at test runtime, so building the
production server binary does not require adding it to the Docker build stage.

Only `vendor/aq-playbooks-{42f9449,a463e59,d3bd349}`, their three matching JSON
pins, and their workspace excludes are removed. The current `0173673` tree,
0.1.3 pin and tar archive are retained. Historical revision identifiers in
tests, examples and protocol snapshots are retained. CI's lint job now runs
both existing playbook-source and lifecycle-contract checks.

The profile utility is renamed to `aq-profile`, including its clap command
name, error prefix, Cargo test binary lookup and README commands.
