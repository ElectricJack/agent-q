# E0 — local full-stack development

Implemented for `smart-falcon-16.1` on 2026-11-02. The development overlay starts
PostgreSQL, pinned aq-graph, supervised aq-git and aq-server with development
authentication and loopback listeners. Cloudflare is disabled by default.
Configured Graph/Git peers participate in bounded, fail-closed readiness at
loopback-only `/dependency-readyz`, exposed by `aq-server dependency-readiness`.
The updater's `/readyz` and `aq-server readiness` retain their original schema
and database-only semantics even when Graph/Git are configured and unavailable.
