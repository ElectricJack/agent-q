# E0 — local full-stack development

Implemented for `smart-falcon-16.1` on 2026-11-02. The development overlay starts
PostgreSQL, pinned aq-graph, supervised aq-git and aq-server with development
authentication and loopback listeners. Cloudflare is disabled by default.
Configured Graph/Git peers participate in bounded, fail-closed readiness at
loopback-only `/dependency-readyz`, exposed by `aq-server dependency-readiness`.
The updater's `/readyz` and `aq-server readiness` retain their original schema
and database-only semantics even when Graph/Git are configured and unavailable.

The scenario checks the shared Git/server image and private paths, and verifies
Graph database ownership `aq_graph:false`. It creates its own Compose project,
state, secrets, database volume,
random loopback ports and bare Git repository. It asserts all four services are
healthy and server dependency reports are ready. It seeds through public APIs,
replays the seed with identical IDs and revision 1, rejects changed inputs,
checks the graph task and Git binding, and verifies exactly one enrolled node.
It kills the serving aq-git engine, observes degraded readiness and a different
supervised process returning to ready. Graph
outage similarly degrades readiness and recovers. Owned containers and volumes
are removed before PASS is emitted. No owner repository is contacted.

The pinned Git service forks a guard and an engine. Killing the guard alone
originally left its engine serving, which correctly failed outage acceptance.
The supervisor now cleans the process group if its guard exits; the acceptance
crash targets the actual serving engine and lets its guard reap helpers and
close its incarnation. Whole-container/guard loss may retain a recovery fence;
automatic fence clearance is intentionally absent and is not qualified here.

## Final review

The fresh read-only whole-branch review found an important credential-replay
defect. A new real-stack regression failed with `seed accepted missing worker
credential`. The fix requires a matching saved node/credential record and a
correlated authenticated `/v1/worker/probe` before accepting replay; it refuses
lost enrollment credentials or database-reset leftovers without replacing nodes.
New credential files are published atomically with private permissions and
without overwriting retained records. The updated Compose test passes all four
missing/mismatched/invalid/truncated refusal cases and recovery to valid replay.
The six Python tests also cover interrupted writes, retained-file preservation
and refusal before enrollment after database reset. No heartbeat is performed.

The review's evidence-attribution correction is incorporated in the table above.
One minor is deferred: the smoke observes Git degradation/recovery but does not
independently assert unchanged server start time/restart count. The reviewed
limits for guard/container loss, private Git remotes, execution/production and
baseline checks remain documented above. The required upstream merge used
`origin/main` under the explicit supervisor waiver recorded above.
